# 周麻婆店长超级助手 V2 项目档案

## 产品目标

让不熟悉经营方法的店长，在手机上只需看数据、点按钮、拍照片或说一段话，就能完成“发现问题—得到建议—执行/分发—回传—验收—复盘”。

## 当前演示边界

- 用户：单一店长角色。
- 门店：三盛广场演示店。
- 日期：8月11日。
- 数据：全部模拟，不连接任何真实业务系统。
- 外部角色：员工、总部、供应商、收银、美团和抖音回执全部在店长端模拟。
- 使用方式：完全自由探索，不设置强制教程。
- 展示方式：公开网页直开即手机工作台，不显示外层手机模型；保留底部五个主菜单。

## 本轮升级重点

- 首页先呈现“下一件最重要的事”，再呈现必做任务、领导下发、自己领取三类每日任务。
- 店务快速处理增加一句话语音下发，AI模拟补齐责任人、截止时间、步骤和验收证据。
- 晨会完成后不结束在结果页，而是明确带店长进入任务接收和后续巡检。
- 数据页增加美团评价、收银 POS、顾客反馈等实时经营信号，异常可直接生成行动。
- 麻婆学院增加黄老师经营课、创始人讲、强店案例和外部精选模拟摘要，并支持一键转任务。

## 核心业务状态

五条核心流程统一使用：

`待处理 → 已确认 → 执行中 → 待验收 → 已完成 / 需帮助`

所有任务必须留下一种以上证据：系统回执、照片、语音、人员确认或经营数据。只有验收通过才发放成长值。

## 演示成功标准

- 测试者无需讲解即可找到五条核心流程。
- 每个核心按钮都会进入下一步或给出明确反馈。
- 刷新页面后进度保留；重置后恢复初始状态。
- 结果页能说清楚谁完成、用什么证据、产生什么经营影响、下一步做什么。
- 页面在 iPhone、Pixel 和普通手机宽度下没有遮挡、溢出或错误键盘。

## 后续阶段

1. 通过本演示确认店长工作台的信息结构和动作闭环。
2. 与经营、技术、供应链、人事确认真实指标、角色和权限。
3. 接入 BI、美团/抖音、任务、人事、采购与库存接口。
4. 小范围门店试用，依据完成率、求助率、任务耗时和经营改善结果迭代。
