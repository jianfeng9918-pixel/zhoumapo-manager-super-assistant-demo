# 周麻婆店长超级助手 V4 演示指南

## 5分钟主线

1. 首页先讲昨日：营业¥98,600，晚市少32位顾客。
2. 看今日预测：预计少¥8,000，系统翻译为约25桌、65位顾客。
3. 点击“查看今日经营剧本”，采用剧本并完成AI晨会。
4. 在“我的—切换经营时段”跳到17:30，完成会员召回与预约跟进。
5. 回到首页查看：当前仍是¥62,000，预计收官已升到¥98,000。
6. 跳到21:30完成复盘，查看实际¥100,600和明日第一项行动。

## 补充演示

- 数据：点开四个经营答案，查看来源、可信度、影响和行动。
- 学院：选择“评分下降怎么办”，把三步做法加入今日剧本。
- 区域联动：从“我的—区域联动演示”切到林阳，下发行动；切回黄店长执行回传，再由林阳确认或退回。
- 求助：店长点击“我做不了，请求帮助”，区域消息中回复后，店长提醒中心同步收到方案。
- 其他店务：从“我的—其他店务动作”查看采购、人事和沽清的轻量入口。

页面始终标注“演示数据”。演示角色、经营时段和全部进度均可在“我的”中重置。
