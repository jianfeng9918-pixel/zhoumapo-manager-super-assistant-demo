# 终局版演示指南

## 推荐演示路线

### 一、店长早晨启动

1. 首屏看“晚市预计少65位顾客”。
2. 点击“开始晨会”。
3. 开始语音、结束并让AI整理。
4. 查看漏项，点击“一句话补充漏项”。
5. 点击“人工确认并下发3项行动”。

观察点：确认之前仅显示“AI预生成、尚未下发”；确认后才出现员工接收回执。

### 二、门店执行与求助

1. 进入“任务—会员召回”。
2. 点击“人工确认执行”。
3. 可先进入“门店资源不够？向林阳申请支持”，确认发送。
4. 返回会员召回，确认发送、回传系统结果并运行AI初验。

观察点：AI初验通过后仍是“等待林阳人工验收”；当前营业额没有因为预计影响而增加。

### 三、区域经理联动

1. “我的—区域与总部联动演示”切换林阳。
2. 首页处理黄店长求助，可直接支持或转总部。
3. “任务”查看会员召回证据。
4. 选择“确认闭环”或“退回补充”。

观察点：确认后店长预计收官升至¥98,000；退回后店长收到具体补充要求。

### 四、总部策略校准

1. 切换“总部经营中心”。
2. 首页点击“校准行动模板”。
3. 查看AI草稿。
4. 点击“人工确认并发布新版本”。

观察点：模板从v3.0升至v4.0，店长收到新版本提醒，审计记录保留。

### 五、收官复盘

1. 回店长端“我的”，切换到21:30。
2. 首页“查看复盘”。
3. 生成AI复盘并由黄店长人工确认。

观察点：页面同时说明目标、预测、实际、有效动作、未闭环事项与明日第一件事。

## 快速重置

店长、区域经理或总部“我的—重置终局演示”。只会删除 `zhoumapo-manager-assistant-final-v1`，V2–V4状态不受影响。
