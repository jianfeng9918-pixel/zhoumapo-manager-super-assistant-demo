# 周麻婆店长超级助手 V3 演示指南

## 演示前

- 建议使用手机直接打开公开链接；电脑端会保持手机宽度居中显示。
- 首次进入应看到 `黄店长，早上好`、`08:50`、当前 `¥8,600`、预计 `¥92,000`、预测缺口 `¥8,000`、健康值 `73`。
- 所有结果均为演示数据。需要重新开始时，进入“我的 → 重置全部演示”。

## 5分钟主讲路线

1. 首页：说明系统先告诉店长“现在最重要”，而不是让他读一堆 BI。
2. 晨会：展示语音记录、漏讲识别、任务拆解和员工回执。
3. “我的 → 演示经营时段”跳到 16:20，点击客单健康指标，展示原因和行动。
4. 完成“增加业绩”行动，回到数据页对比预计收官从 ¥92,000 变为 ¥98,000，健康值从 73 变为 76。
5. 切换“林阳·区域经理”，下发跨角色任务；切回黄店长拍照回传，再由区域确认或退回。
6. 跳到 21:30，展示实际收官 ¥100,600、三条复盘结论、日报和明日任务。

## 自由测试清单

- 首页提醒能否进入对应诊断或任务，并减少未读数。
- 采购到货后能否拍照验收并解除库存风险。
- 人事考核是否只给事实和建议，最终决定保留给店长。
- 菜品沽清是否显示收银、美团、抖音三个模拟回执和恢复上架。
- 四个“我想提升”目标是否都能领取、回传和看到经营影响。
- 区域任务是否支持确认闭环与退回补拍两条分支。
- 店长求助后，区域消息是否收到；区域回复后，店长提醒是否同步。
- 刷新页面后进度是否保留；重置后是否恢复 08:50。

## 讲解口径

这不是已经接入真实业务系统的正式产品，而是一套用于确认信息结构、操作方式和业务闭环的 V3 交互演示。正式版本仍需接入 BI/收银、渠道、任务、人事、采购库存和权限系统。
