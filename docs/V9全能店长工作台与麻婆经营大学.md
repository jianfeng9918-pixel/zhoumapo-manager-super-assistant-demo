# V9 全能店长工作台与麻婆经营大学

## 1. 产品定位

V9 不把店长限制在一条故事演示里，而是在“一日经营陪跑”主线之外补齐每天常用的工作入口、系统学习和个人工作中心。店长的主要操作仍是：按住说话、拍一张、点一下、人工确认一次。

## 2. 五栏信息架构

- 今日：1.5屏智能工作台。首屏是经营判断、经营数字、主行动、语音、任务概况和四个快捷入口；后半屏是两条动态、一门推荐课程和全天路线。
- 数据：今日/7日/本月，以及流量会员、菜品、口碑、库存损耗、人员执行和行动效果专题。
- 任务：工作分工、营业关键节点、待回传、待验收、负责人筛选和可折叠经营时间线；不再重复首页主行动。
- 学院：麻婆经营大学，六类18课、三条路径、搜索、语音提问、小测、收藏和实操。
- 我的：个人信息、今日目标、任务/报表/学习/收藏、月度成长、晋升条件、经营记录与折叠演示工具。

## 3. 首批18个脱敏课程

| 分类 | 课程 |
|---|---|
| 业绩增长 | 看懂今日营业缺口、客单提升3步法、90秒收官复盘 |
| 流量与会员 | 会员召回实操、社群每周新增40人、高峰15秒表达 |
| 菜品与菜单 | 鲜椒鸡推荐话术、菜单结构快速检查、菜品动销日报 |
| 采购库存沽清 | 安全库存怎么定、采购申请5步、菜品沽清与恢复 |
| 顾客体验口碑 | 等菜问题责任链、差评24小时复盘、一张照片完成巡检 |
| 团队管理带教 | 3分钟晨会、新人7天带教、任务验收不返工 |

公开 Demo 的课程是从周麻婆经营方法、话术、评价复盘、用户旅程和系统操作中提炼的脱敏模拟内容，不暴露原始内部文件。正式知识只有总部人工发布后才能进入 AI 建议。

## 4. 店务轻闭环

采购：库存预警 → AI草稿 → 店长确认数量预算 → 提交申请 → 模拟到货回执 → 拍照验收。AI不付款，不代替正式审批。

沽清：库存不足 → 店长确认沽清 → 推荐替代菜 → 模拟收银/美团/抖音同步 → 库存恢复 → 重新上架。正式系统必须由平台回执替换模拟结果。

## 5. 接口接续

- `BusinessDataAdapter.getHomeWorkbench()`：未来聚合 POS、任务、评价和库存提醒。
- `KnowledgeAdapter`：分类、路径、内容详情、搜索；真实实现接总部知识库与审核版本。
- `StoreOperationsAdapter`：采购、库存和渠道同步轻流程；真实实现接 ERP、审批与平台接口。
- `VoiceInteractionAdapter.resolveIntent()`：所有语音返回 `requiresConfirmation: true` 和预填草稿。
- Reducer：学习进度、收藏、店务步骤、任务证据和审批继续使用统一状态与本地审计。

## 6. 演示路线

1. 首页按住说话进入晨会，确认后生成行动。
2. 首页打开采购申请，连续完成到货拍照验收。
3. 打开库存与沽清，看到替代菜及三渠道模拟回执。
4. 学院切换六类，打开“会员召回实操”，完成小测并马上实操。
5. 我的查看二星升三星条件、经营记录和折叠演示工具。

## 7. 边界

- 状态键：`zhoumapo-manager-assistant-final-v5`。
- 全部数据与图片回执为演示数据。
- 不自动付款、审批、处罚、验收、发布或对外发送。
- 店长日常页面不显示健康值、六维评分或指定个人求助话术。
