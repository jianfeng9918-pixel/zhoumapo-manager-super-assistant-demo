# 周麻婆店长超级助手 V4 · AI区域经理经营陪跑版

面向普通店长的手机版经营陪跑演示。系统不要求店长理解复杂指标，而是把数据翻译成“今天预计少多少桌、少多少顾客”，再带着店长完成晨会、召回、预约确认、现场检查和收官复盘。

> 全部门店、金额、顾客、预约、会员、员工、评价、证据及AI结论均为模拟数据，仅用于产品演示。

## V4主故事

1. 08:30查看昨日复盘：实际营业¥98,600，晚市少32位顾客。
2. 查看今日预测：预计¥92,000，缺口¥8,000，约25桌、65位顾客。
3. 采用《8月11日晚市顾客追回剧本》，通过AI晨会生成5项行动。
4. 执行会员召回与预约跟进，补回19桌、49位顾客；当前营业额不虚增，预计收官提升到¥98,000。
5. 关注10桌晚市体验并复查结果，21:30实际收官¥100,600。

## 五个页面

- 今日：昨日复盘、今日预测、实时进度和唯一主要行动。
- 数据：回答能否达标、差在哪里、为什么、现在怎么办。
- 任务：以时间轴呈现经营剧本，不做传统待办列表。
- 学院：自动带入当前问题，匹配总部SOP和优秀门店模拟案例。
- 我的：四项店长能力、任务证据、区域联动和演示工具。

区域经理保留为“我的”中的二级演示，可走通区域下发、店长执行、证据回传、确认/退回和求助回复。采购、人事、沽清只以轻量行动出现，不再占首页。
