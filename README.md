# 周麻婆店长超级助手 V2 · 直开升级版

面向周麻婆门店店长的手机操作台交互演示。它不是一张静态数据看板，而是把经营问题直接转成店长下一步能执行、能分发、能回传、能验收的动作。

> 本项目中的门店、营业额、评价、员工、库存、采购、渠道回执与 AI 判断全部为模拟数据，仅用于产品演示。

## 演示内容

- 今日操作台：营业额、预测、差额、健康值、下一件最重要的事和行动时间线。
- 每日任务：清楚区分必做任务、领导下发和自己领取，并单独查看店长语音下发的任务。
- AI 晨会：语音转写、事项识别、任务拆解、人员分配、接收回执与完成反馈。
- 智能采购：库存预警、AI 采购量、预算、供应商、配送、拍照验收。
- 人员考核：事实依据、AI 草稿、店长判断、带教任务与员工确认。
- 菜品沽清：库存预警、收银/美团/抖音同步、替代推荐、恢复上架。
- 主动提升：增加业绩、增加客流、提高评分、控制成本四类行动。
- 语音下发：模拟录音、AI补齐责任人/时间/验收方式、员工接收回执和任务入栏。
- 经营数据：美团评价、收银 POS、顾客反馈、渠道漏斗、口碑和成本信号均可直接转成行动。
- 麻婆学院：黄老师经营课、创始人讲经营、强店案例和外部精选摘要，内容可一键转任务。
- 数据、任务、晋升与成长值。
- 本地保存演示进度，并可在“我的”中一键重置。

公开演示采用“直接打开就是手机工作台”的方式，不再显示外层手机边框或设备选择器；手机全屏，电脑端居中呈现。

## 推荐测试入口

所有模块均可自由探索。第一次测试可从首页依次点击：

1. `开晨会`
2. `采购下单`
3. `菜品沽清`
4. `人员考核`
5. `我想提升`

每条流程最后都会出现统一的“证据—AI 验收—经营影响—成长奖励—下一步”结果卡。

## 后续真实接口接入

当前状态集中保存在 `src/Prototype.tsx` 的本地模拟数据层。正式开发时可在不改变页面和状态机的前提下，分别替换为：

- BI/收银：业绩、客流、转化、客单、毛利与损耗。
- 美团/抖音：渠道流量、评价、菜品上下架与同步回执。
- 供应链：库存、采购单、供应商、配送与到货验收。
- 人事：排班、考勤、任务完成、考核与晋升条件。
- 任务中心：总部下发、员工接收、证据上传与验收结果。

正式接口还需要补充门店身份、角色权限、数据鉴权、操作日志、失败重试与真实通知机制。
