# 周麻婆店长超级助手 V3 · AI值班长与双角色联动版

面向周麻婆门店的手机经营操作台演示。店长打开后不需要先学经营或填写复杂表格，系统会根据经营快照告诉他“现在最重要的一件事”，并把问题带到行动、证据、验收和结果。

> 全部门店、营业额、评价、员工、库存、采购、平台回执与 AI 判断均为模拟数据，仅用于产品演示，不代表真实经营结果。

## V3 演示重点

- 动态今日作战台：清楚区分当前完成、距离目标、预计收官和预测缺口。
- 全天主线：08:50 晨会 → 11:30 午市巡检 → 14:30 经营诊断 → 16:20 晚市纠偏 → 17:00 晚市保障 → 21:30 收官复盘。
- 六维健康：流量、转化、客单、口碑、成本和人员均可进入“异常—原因—来源—置信度—行动—复查”诊断。
- 任务地图：区分必做、总部、区域、AI推荐、自主领取和店长下发，展示责任人、截止、证据、催办、贡献和成长值。
- AI晨会：语音波形、实时提取、完整度检查、漏项补充、冲突检查、员工回执和任务地图联动。
- 拍照巡检：模拟拍照识别、自动整改、补拍复验和前后对比。
- 店务闭环：采购、人事带教、菜品沽清、经营提升全部联动健康值或预测结果。
- AI主动提醒：提醒可直接进入对应诊断或任务，处理后未读数同步减少。
- 收官复盘：目标、预测和实际对比，三条 AI 结论，未完成事项转明日任务并生成日报。
- 双角色联动：林阳区域经理下发 → 黄店长接收执行 → 照片回传 → 区域确认或退回补拍。
- 求助联动：黄店长一键求助，区域经理回复或转总部，回复同步回店长提醒中心。
- 本地保存 V3 进度；“我的”可切换角色、跳转时段或一键重置到 08:50。

## 建议演示路线

### 店长全天主线

1. 首页点击“开始执行”，完成六步 AI 晨会。
2. 完成午市拍照巡检与补拍复验。
3. 点击客单健康指标，领取“增加业绩”行动并回传证据。
4. 处理晚市库存与菜品沽清。
5. 完成 21:30 收官复盘并生成明日任务。

### 跨角色闭环

1. 点击首页“演示角色”，切到“林阳·区域经理”。
2. 进入三盛广场演示店，语音下发“晚市主动推荐训练”。
3. 切回黄店长，在区域任务中接收、执行并拍照回传。
4. 再切回区域经理，在任务中确认闭环或退回补拍。
5. 切回黄店长，查看预计收官和成长值变化。

所有页面均可自由探索，不设置强制路线。每个核心按钮都会进入下一步或给出明确反馈。

## 实现边界与未来接口

- `src/demo-model.ts`：角色、时段、经营快照、健康权重、提醒、跨角色任务和区域门店模拟数据。
- `src/Prototype.tsx`：店长/区域经理页面、业务状态机和跨角色联动。
- `src/prototype.css`：延续已确认的白底、暖红、圆角行动卡片和手机小程序视觉。
- 本地存储键：`zhoumapo-manager-assistant-v3`，不会读取或覆盖 V2 进度。

正式开发时分别替换 BI/收银、美团/抖音、库存采购、人事排班、任务中心与通知接口，并补充真实身份、角色权限、数据鉴权、操作日志、失败重试和人工复核。AI 不自动处罚员工、不自动付款，也不代表真实平台已经同步。
