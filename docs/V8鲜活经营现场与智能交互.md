# V8 鲜活经营现场与智能交互

## 交付定义

V8 是直接对外展示与交给日华继续接口开发的版本。它不展示密集BI或功能宫格，而是用一个店长的完整一天说明：

`经营信号 → AI判断 → 语音/按钮确认 → 执行 → 证据 → AI初验 → 人工验收 → 数据重算 → 方法沉淀`

## 视觉与交互

- 暖白背景，行动红 `#D83328`，AI蓝紫 `#5B57E8`，机会橙 `#F39A22`，结果绿 `#35A85B`。
- 每屏只有一个实心红色主行动；颜色不作装饰性评分。
- 数字变化必须显示来源。例如“会员召回与预约跟进新增19桌预约”，同时标注“实际营业未虚增”。
- 所有图片使用 `StoryMedia`记录用途、来源、替代文本和演示标记；正式版由素材服务替换。
- 所有动画在 `prefers-reduced-motion: reduce` 下直接呈现结果。

## 模型与接口

- `LiveOperatingFrame`：实时经营快照。
- `MetricTransition`：数字前后、触发动作及预计/实际属性。
- `VoiceSession / VoiceIntent`：语音会话和问数、开会、行动、回传、求助、报告意图。
- `VisualReport`：结论、证据、可视趋势、图片证据、原因链和唯一行动。
- `BusinessDataAdapter.getLiveFrame / subscribeLiveFrames`：未来接POS/BI拉取和实时推送。
- `VoiceInteractionAdapter.resolveIntent`：未来接语音识别与意图理解。
- `ReportingAdapter.getVisualReport`：未来由服务端统一经营报告口径。

## 验收口径

- 页面不显示健康分、六维评分、订货或排班主线。
- 语音只预填，正式动作必须生成 `ApprovalRecord`。
- 会员召回和预约跟进只先更新预测/顾客缺口；只在收官且关键行动完整闭环后显示真实 `¥100,600`。
- 全部数据、图片、AI判断和平台回执均为显著标识的演示内容。
