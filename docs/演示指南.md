# V7 一日经营陪跑与经营报告演示指南

## 0. 新增的经营报告演示

在店长端点击底部“数据”：

1. 首先看到今日经营答案，而不是指标矩阵。
2. 进入“今日经营战报”，展开趋势、原因链、数据来源与换算口径。
3. 从“菜品经营”人工确认生成“爆炒鲜椒鸡推荐话术”行动。
4. 点击“直接问经营数据”，演示四个自然语言问题。
5. 进入“行动效果账本”，对比预计影响、预约结果、真实到店和实际营业。
6. 从报告详情生成长图、日报、7日复盘或语音简报草稿；系统不会真实发送。

切换林阳区域经理：首页或“门店”进入“区域7日经营复盘”，查看六店缺口、介入顺序和有效动作。

切换总部经营中心：首页或“策略”进入“总部行动效果复盘”，从跨店证据进入策略校准。

## V6 全天经营主线

## 推荐演示路线

### 一、店长早晨启动

1. 首屏看“晚市预计少65位顾客”。
2. 点击“开始晨会”。
3. 开始语音、结束并让AI整理。
4. 查看漏项，点击“一句话补充漏项”。
5. 点击“人工确认并下发3项行动”。

观察点：确认之前仅显示“AI预生成、尚未下发”；确认后才出现员工接收回执。

### 二、午市复查与下午判断

1. “我的—切换经营时段”切到12:00。
2. 首页点击“拍照复查”，模拟拍一张午市现场。
3. 观察AI识别整洁、人员到岗和传菜口等待风险，并自动推进14:30。
4. 进入经营剧本，人工确认晚市剧本后推进17:30。

观察点：店长不填写巡检表；当前收入、正常应完成、预测和顾客缺口分开表达。

### 三、门店执行与求助

1. 进入“任务—会员召回”。
2. 点击“人工确认执行”。
3. 可先进入“门店资源不够？向林阳申请支持”，确认发送。
4. 返回会员召回，确认发送、回传系统结果并运行AI初验。
5. 进入“预约跟进”，确认跟进10桌、回传确认记录并运行AI初验。

观察点：AI初验通过后仍是“等待林阳人工验收”；当前营业额没有因为预计影响而增加。

### 四、区域经理联动

1. “我的—区域与总部联动演示”切换林阳。
2. 首页处理黄店长求助，可直接支持或转总部。
3. “任务”分别查看会员召回、预约跟进证据并逐项人工验收。
4. 分别打开会员召回、预约跟进和晚市现场证据，选择“确认这项闭环”或“退回补充”。

观察点：召回验收后先升至¥95,800并剩34位顾客；预约跟进验收后才升至¥98,000并剩16位顾客。退回后店长收到具体补充要求。

### 五、总部策略校准

1. 切换“总部经营中心”。
2. 首页点击“校准行动模板”。
3. 查看AI草稿。
4. 点击“人工确认并发布新版本”。

观察点：模板从v3.0升至v4.0，店长收到新版本提醒，审计记录保留。

### 六、收官复盘

1. 回店长端完成“晚市10桌体验”并回传照片。
2. 林阳人工验收第三项证据。
3. 系统自动进入21:30；首页点击“查看复盘”。
4. 生成AI复盘并由黄店长人工确认。

观察点：未完成关键动作时显示真实未完成结果，不固定显示¥100,600；页面先显示经营结果，再显示明日动作，最后显示成长证据。
