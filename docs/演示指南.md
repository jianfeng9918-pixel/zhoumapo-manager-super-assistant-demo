# V9 全能店长工作台与麻婆经营大学演示指南

## 建议开场

V9不是传统BI，也不是单一故事页。它把店长每天高频使用的经营判断、任务、店务、学习和个人工作收在同一个手机入口中。所有页面均使用模拟数据，所有正式下发、采购申请和渠道操作均需人工确认。

## 一、今日工作台

1. 首屏先看AI经营判断、实际/预测/顾客缺口和唯一主行动。
2. 轻点“按住说话”查看常用话术；长按350毫秒开始，松开发送，上滑取消。
3. 查看今日任务概况，并进入开晨会、拍照巡检、采购申请、库存与沽清四个快捷工作。
4. 向下滑动查看经营动态、今日学习推荐和全天经营路线。首页总长度控制在约1.5屏。

观察点：信息完整但不做密集看板；店长始终知道现在最重要的动作。

## 二、晨会与任务闭环

1. 点击“开始晨会”，模拟语音转写。
2. 查看AI提取的目标、负责人和漏讲事项。
3. 人工确认后才正式生成并下发行动。
4. 从“任务”查看全部、必做、AI建议、上级下发和我下发。
5. 完成动作后回传照片、语音或系统证据，查看AI初验和业务反馈。

观察点：任务不是OA待办，而是带来源、负责人、截止时间、证据和经营贡献的行动。

## 三、数据与常用报表

1. 在“数据”切换今日、7日和本月。
2. 查看流量会员、菜品、口碑、库存损耗和人员执行专题。
3. 每份报告按“结论—证据—趋势—原因—行动”展开，原始口径折叠查看。
4. 生成日报、周报或语音简报草稿；系统不会自动外发。
5. 报表转行动前必须由店长人工确认。

观察点：数字先翻译成顾客、桌数、菜品份数或具体动作，再提供底层数据。

## 四、采购与库存沽清

### 采购申请

1. 首页点击“采购申请”。
2. 查看库存预警和AI采购草稿。
3. 店长确认后提交模拟申请。
4. 查看到货回执并拍照验收。

### 库存与沽清

1. 首页点击“库存与沽清”。
2. 对库存不足菜品选择补货或沽清。
3. 查看收银、美团和抖音的模拟同步结果及替代菜建议。
4. 库存恢复后人工确认重新上架。

观察点：Demo不自动付款，也不代表真实渠道已经同步。

## 五、麻婆经营大学

1. 使用搜索或语音提问进入当前经营问题。
2. 浏览业绩增长、流量与会员、菜品与菜单、采购库存与沽清、顾客体验与口碑、团队管理与带教六大分类。
3. 进入“新店长7天入门”“流量增长实战”“菜品进销存操作”三条学习路径。
4. 任意打开18项课程之一，查看素材、三步方法、现场小测和来源版本。
5. 完成小测、收藏课程，再选择“马上实操”或“加入今日行动”。

观察点：学习不是独立课程库，课程必须能回到门店当天行动。

## 六、我的工作中心

1. 查看店长和门店信息、今日目标、任务闭环与学习进度。
2. 进入我的任务、我的报表、我的学习和我的收藏。
3. 查看本月有效方法、连续完成、证据完整度和二星升三星路径。
4. 展开“演示与帮助”后可切换角色、经营时段或重置V9。

## 七、三角色联动

区域经理和总部只在支持、验收和策略发布时出现，不抢店长主线：

1. 店长确认发送支持申请。
2. 区域经理查看上下文，回复方案、验收证据或退回补充。
3. 总部根据跨店证据修订行动模板，人工确认后发布新版本。
4. 店长端同步结果和审计记录。

## 快速重置

从“我的—演示与帮助—重置V9演示”恢复初始状态。系统只删除 `zhoumapo-manager-assistant-final-v5`，不会读取或覆盖V2至V8的演示进度。
